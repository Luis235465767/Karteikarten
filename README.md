# Physiologie – Karteikarten & Quiz

Lernapp mit Karteikarten (Leitner-Wiederholungssystem), Multiple-Choice-Quiz und offenen Fragen.

- Lerninhalte: `inhalte/` (ein Lernzettel pro JSON-Datei, Themen in `inhalte/themen.json`)
- Tests: `npm test`, Inhaltsprüfung: `npm run pruefen` (Node 20 oder neuer, keine Abhängigkeiten)
- `legacy/`: die ursprüngliche claude.ai-Version und die eingefrorene Zuordnung alter Indizes zu IDs

Die vollständige Anleitung folgt mit der fertigen App.
